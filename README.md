# The GZone Rap Battle

The official website for The GZone Rap Battle platform. This repository contains the frontend web application.

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```
   The site will be available at `http://localhost:5173` (or the port specified in your console).

3. **Build for production:**
   ```bash
   npm run build
   ```
   The built files will be output to the `dist` directory.

## Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
